# Examples — what "the user wants" looks like

Seven complete briefs → direction locks → storyboards. They are **calibration**, not templates: read the two that are closest to your task, then *invent something else of equal ambition*. Each follows the same anatomy so you can learn the pattern:

1. **The prompt** — what the user actually typed (usually 1–3 sentences).
2. **Direction lock** — art direction, world, hero, signature move, palette, forbidden list.
3. **Creative statement** — the 5-line pitch you give first.
4. **Storyboard** — scroll ranges, shot, what changes, copy (≤ 12 words).
5. **Signature move** — how to implement the one thing people will screenshot.
6. **The lazy version** — what a no-skill agent builds, and why it loses.

## The universal quality delta (skill vs. "just ask it")
| Just asking an AI | With AURA |
| --- | --- |
| Spinning cube/torus + gradient + fade-up cards | One authored world, one camera, scroll = playhead |
| Default lights, no env map | Key/rim/fill/practical + designed environment map |
| One depth plane | ≥ 5 depth planes every frame |
| Inter 64 px centred | Giant fitted type the world occludes and reflects |
| "Looks good" | 12 frames × 3 viewports, scored ≥ 85/100, three polish loops |
| Desktop only | Designed mobile edit, reduced-motion edit, no-WebGL poster |
| A hero | A hero + end-state + routes + metadata + hand-off |

## Weak vs strong prompt (the skill makes both work, but know the difference)
- Weak: *"make a 3D website for my earbuds"* → the skill runs Intake, **decides** the direction, states assumptions, and builds.
- Strong: *"Earbuds called NOCTA, matte graphite with a mint LED, for night-shift workers; feel: silence made physical; CTA: pre-order; palette cold + mint"* → the skill locks it in 30 s and spends the time on craft.
