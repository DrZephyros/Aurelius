## 2026-11-29 · AURA v19 — fixes you can act on, a designed fallback, a better reference (answers the v18 starter audit)

### Audit findings → what was done
1. **Impossible fix suggestions ("≈1133 %").** Root cause: polarity was guessed from the backdrop's 90th percentile, so light text over bright bokeh was treated as *dark* text and the formula divided into nonsense. `audit.mjs` v4 takes polarity from the **glyph colour**, works in **sRGB** (where CSS composites), and answers with one concrete move: `--aura-plate-a: X on <chapter> (now Y)`, `swap .aura-left ↔ .aura-right` (only if the mirrored rect was measured clear), `move the SUBJECT out of this text band (a–b % of the frame)` when no scrim ≤ 0.92 works, or a text-colour / scrim-colour note. Worst frame per chapter wins. Never > 100 %.
2. **Example failed its own contrast gate.** New *local plate* under every `.aura-copy` (`--aura-plate-a`, 0.55; 0.62 phone) and a faint plate under giant words; near-bokeh opacity 0.35 → 0.2 and count −25 %; phone rail parks the hero lower (`look.y` above the hero) and the phone title sits at 15 % instead of 22 %.
3. **Landscape collision (844×390, 180×16 px).** Giant title now top band (22 %, ≤ 34 vh), side copy bottom band; collision findings name both chapters, windows and anchors.
4. **No-WebGL page: no action, serif body.** `AuraExperience` builds `.aura-static-head` (title · lede · first `a[href]`/`button`) above the fold; `.aura-root` sets `font-family: var(--aura-body)` and every stack ends in a generic family. New blockers `fallback-font`; `fallback-no-action` now distinguishes "none anywhere" from "below the fold".
5. **Craft 3/15.** `scene.example.ts` rebuilt: creased sculpted hero (not an orb), a *gate* of leaning obsidian slabs on an arc open toward the camera, thin iridescent chips replacing flat tetrahedra and dissolving inside 5 world units of the lens (the black triangle), five chapter moods through the new `mood.ts` (ink → glacier → ember → violet → dawn) incl. live split-toning (engine now re-reads `scene.grade` every frame).
6. **Mobile = shrunk desktop.** Labels 14 px, body 17 px, headings up to 3 rem, hero re-framed on the phone rail, chapters hidden until the first frame binds (fixes the ghosted CTA pill).
7. **Reproducibility.** `starter/package-lock.json` committed; `npm ci` verified (dry-run) in a clean tree. `npm run setup` (new) installs Chromium and proves WebGL launches, printing the single system-library fix if not.
8. **Broken TASTE.md reference.** `templates/TASTE.template.md` ships (with 3/7/10 anchors per row); `starter/TASTE.template.md` is its copy (generated by `scripts/gen-skill-raw.mjs`); the audit copies it with the fingerprint and automated score filled in.
9. **The example sets the bar.** SKILL.md §8 now says a scene shipped with blockers is not "passing with notes"; the honesty line is mandatory.

## 2026-11-28 · AURA v18 — frontier edition (answers the v16/v17 benchmark report)

### Quality gate
- `audit.mjs` v3 is **class-agnostic**: text/CTA/tap/collision checks come from the rendered DOM; chapter-rhythm checks run only when chapters exist (`aura.audit.json` to name them) and are skipped, never failed. `.tw-cta` is no longer a `no-cta` blocker.
- **The scrim is visible to the gate.** Contrast = per-glyph-pixel, measured against a frame with transparent glyphs (scrim, overlay gradients, button fills kept) + a glyphs-only alpha mask. Each finding prints the measured scrim increase that fixes it; giant words are judged on their letters, not their line box. Fix-loop for persistent giant-word blockers documented in ref 18 §6.
- Gate vs starter is now separable: `report.json` stamps `auditVersion`, profile and every threshold; `--compare` lists new/fixed findings and says when the gate itself changed. Score is a per-rule-capped **hygiene floor**; `TASTE.md` is the shipping rubric.
- Fallbacks verified: no-WebGL must show ≥120 chars + an action + no stuck loader; reduced motion must really stop (frame equality 1.5 s apart, `info().motion.frozen`, no infinite CSS animation). Asset 404s and 200-as-HTML SPA fallbacks are blockers. `--tsc`, `--serve` (honest 404s), `--throttle`, `--poster`.

### Mobile
- Measured device budget (`device.ts`: GPU string + RAM/cores + a calibration shader in ms/MP → tier + Budget) replaces `w<760 || coarse`; bidirectional governor (down fast, up slow, flap-guarded). `?aura-debug=1` + `__aura.perf()` for real devices — **still unmeasured on real hardware from here**.
- CTA 16px / 56px, HUD + labels ≥12px, new landscape-phone rules (narrow column, height-capped giant type).

### Frontier
- Shipped as code: SDF/metaball hero (`RawShaderMaterial`, GLSL3, `gl_FragDepth`), GPU curl-noise particles, Gaussian splats (+ `.splat` loader), AO + bokeh DOF from a `DepthTexture` pre-pass, `CubeCamera` live probe, procedural WebAudio score with Sound toggle, WebGPU/TSL compute track (type-checked, **not executed** — no adapter in CI). SSR deliberately not faked.
- `looks.ts` (6 looks) + `scene.meridian.ts` (`?world=meridian`, light mode, cyclorama, no mirror floor) + site route `/frontier`.
- Bug found while building it: `ShaderPass` clones uniforms and a cloned `DepthTexture` is empty → AO/DOF silently read nothing. Fixed by re-binding the real texture; documented in `post.ts`.

### Engine / portability / hygiene
- `contract.ts` (types only) + `createMinimalHost` + `adaptLegacy` + `railSampler`: per-shot `at`, pointer, quality, reduced motion no longer need a shim. Reduced motion freezes `Frame.time`.
- `skill-src` is the single source; `VERSION` + `skill.json` (sha256 manifest) generated by `scripts/gen-skill-raw.mjs`. `three` pinned exact (0.187.0); starter tsconfig has `noUnusedLocals/Parameters`, `npm run typecheck` is clean.

### Known gaps
- Meridian audited on desktop software-GL only in this session; mobile/landscape/wide, NOCTA/Umbra/Mira/Obsidian re-audits still owed. SDF edges are aliased without MSAA (software GL / low tier).
- Not retro-fitted: `src/bundles/engine.ts` still hosts the legacy shape; use `adaptLegacy` + `createMinimalHost` to move Tidewell/Altai/Helm/Yoru.

  - `skill-studio.tsx`: unused `useState`.
  - `skill-src/aura-3d-web/starter/src/aura/scene.umbra.ts`: unused `quality`.

**Library endpoint (`/library/*`, `/llms.txt`)**
- Live `llms.txt` returns 200 `text/markdown` and matches the local build byte-for-byte (20,716 bytes).
- All 110 linked items return 200 `text/markdown`.
- **Critical:** unknown paths also returned 200 `text/markdown` with an SPA HTML body, because the `/*` → `/index.html` redirect masked every 404. Agents couldn't tell a miss from a hit.
- **Critical:** all 24 templates link `../_shared/base.css`, which isn't shipped anywhere in the library. Without it the pages render unstyled (the hero copy is invisible and the sections collapse). Confirmed in a browser on the Folio template.
- Templates also depend on `../_shared/` and `../_vendor/` relative paths. These don't resolve from a flat download folder, and `three` isn't bundled.
- A cheap model that copies a template would get an unstyled page and spend its budget debugging paths.

### Changes this session (uncommitted)

- `scripts/build-agent-files.mjs`: writes `dist/library/not-found.md` (the 404 target).
- `src/lib/agent-library.ts`: each template is now a flat five-file project:
  - `index.html`, `style.css`, `main.js`
  - `shared/base.css` and `shared/core.js`, both now included in the markdown

  - The generator rewrites `../_shared/` to `./shared/` and the `_vendor` paths to the CDN.
  - Each template has a "Project layout" section, a "Notes for the agent" section that says to serve over http, and a verify step (zero console errors, a top and a scrolled screenshot).
